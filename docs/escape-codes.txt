1. About this document

    This document contains a list of escape codes that were encountered while experimenting on this project.
    Personal reference index. Captured on unix and represented as byte (or byte arrays)

2. Special Characters

    UPARROW         - \x1b[A
    DOWNARROW       - \x1b[B
    RIGHTARROW      - \x1b[C
    LEFTARROW       - \x1b[D

    For more, just do 
    
    +++ 
    cat -v
    +++ 
    
    and print stuff

3. Cursor Controls

    Hide Cursor     - \033[?25l
    Show Cursor     - \033[?25h
